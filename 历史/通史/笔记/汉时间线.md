
| 时间                   | 人物          | 事件                                      |
| -------------------- | ----------- | --------------------------------------- |
| **公元前 206~ 前 202 年** | 楚汉之争（刘邦、项羽） | 鸿门宴；项羽分封诸侯；彭城之战、成皋对峙；垓下之战，项羽乌江自刎，楚汉之争结束 |
| **公元前 202 年**        | 汉高祖・刘邦      | 刘邦称帝，定都长安，**西汉建立**                      |
| **公元前 200 年**        | 汉高祖・刘邦      | 白登之围，西汉与匈奴开启和亲政策                        |
| **公元前 180~ 前 157 年** | 汉文帝・刘恒      | 推行休养生息，轻徭薄赋，开启**文景之治**                  |
| **公元前 157~ 前 141 年** | 汉景帝・刘启      | 平定**七国之乱**，加强中央集权；延续文景之治                |
| **公元前 141~ 前 87 年**  | 汉武帝・刘彻      | 罢黜百家、独尊儒术；颁布推恩令；卫青、霍去病北击匈奴；张骞出使西域；盐铁官营  |
| **公元前 87~ 前 49 年**   | 汉宣帝・刘询      | **昭宣中兴**；设**西域都护府**，西域正式归属中央管辖          |
| **公元 8 年**           | 王莽          | 王莽篡汉，建立新朝，**西汉灭亡**                      |
| **公元 8~23 年**        | 新朝・王莽       | 王莽改制（王田、私属、五均六筦）；绿林、赤眉农民起义爆发            |
| **公元 23 年**          | 绿林军         | 绿林军攻入长安，王莽被杀，**新朝灭亡**                   |
| **公元 25 年**          | 汉光武帝・刘秀     | 刘秀称帝，定都洛阳，**东汉建立**；平定割据，开创**光武中兴**      |
| **公元 57~88 年**       | 汉明帝、汉章帝     | **明章之治**；班超经营西域；蔡伦改进造纸术                 |
| **公元 184 年**         | 汉灵帝         | **黄巾起义**爆发，东汉统治名存实亡                     |
| **公元 220 年**         | 汉献帝・刘协      | 曹丕篡汉，汉献帝禅位，**东汉灭亡**，历史进入三国时期            |
