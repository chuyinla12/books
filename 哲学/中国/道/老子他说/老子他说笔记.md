

# 一

![[南怀瑾 老子他说.pdf#page=48&rect=48,485,391,512|南怀瑾 老子他说, p.34]]


> 道可==道==，非常道；名可名，非常名。无名天地之始，有名万物之母。==故常无,==，欲以观其妙；==常有==，欲以观其徼（jiào）。==此两者同出而异名==，同谓之==玄==，玄之又玄，众妙之门。

- 南怀瑾看法：
	- “道可道”的第二个道不是说：
		![[南怀瑾 老子他说.pdf#page=49&rect=42,73,387,221|南怀瑾 老子他说, p.35]]
	- “常无，欲以观其妙，常有，欲以观其徼”
		- 常无：从 “无” 的层面
			![[南怀瑾 老子他说.pdf#page=51&rect=41,244,381,326|南怀瑾 老子他说, p.37]]
			![[南怀瑾 老子他说.pdf#page=51&rect=46,63,370,146|南怀瑾 老子他说, p.37]]
		- 现在另一种说法是：
			- 常无欲：欲，欲望
	- 玄与元可互换
		![[南怀瑾 老子他说.pdf#page=52&rect=47,114,378,242|南怀瑾 老子他说, p.38]]
	- “此两者==同，出==而异名”

# 二

> 天下皆知美之为美，斯恶已；皆知善之为善，斯不善已。故有无相生，难易相成，长短相较，高下相倾，音声相和（hè），前后相随。==是以圣人处无为之事，行不言之教，万物作焉而不辞，生而不有，为而不恃，功成而弗居。夫唯弗居，是以不去==。

# 三
![[南怀瑾 老子他说.pdf#page=65&rect=31,492,392,534|南怀瑾 老子他说, p.51]]

> 不尚贤，使民不争；不贵难得之货，使民不为盗；不见（==xiàn，现，出现==）可欲，使民心不乱。是以圣人之治，==虚其心，实其腹==；弱其志，强其骨。常使民无知无欲，使夫智者不敢为也。为无为，则无不治。

- ”民“不是君主视角的“人民”，而是”天下的人们“
	![[南怀瑾 老子他说.pdf#page=65&rect=40,96,368,209|南怀瑾 老子他说, p.51]]

	- 贤能带来的权力使得社会不平等

	- 盗还是相互的

# 七
![[南怀瑾 老子他说.pdf#page=121&rect=42,479,406,522|南怀瑾 老子他说, p.107]]

> 天长地久。天地所以能长且久者，以其不自生，故能长生。是以圣人后其身而身先，外其身而身存。非以其无私邪（yé）？故能成其私。

# 八
![[南怀瑾 老子他说.pdf#page=124&rect=44,494,407,526|南怀瑾 老子他说, p.110]]

> 上善若水。水善利万物而不争，处众人之所恶（wù），故几（jī）于道。居善地，心善渊，与善仁，言善信，正善治，事善能，动善时。夫唯不争，故无尤。

# 九
![[南怀瑾 老子他说.pdf#page=127&rect=35,484,399,523|南怀瑾 老子他说, p.113]]

# 十一
![[南怀瑾 老子他说.pdf#page=147&rect=39,487,402,524|南怀瑾 老子他说, p.133]]

> 三十辐共一毂（gǔ），当其无，有车之用。埏埴（shān zhí）以为器，当其无，有器之用。凿户牖（yǒu）以为室，当其无，有室之用。==故有之以为利，无之以为用。==

# 十二
![[南怀瑾 老子他说.pdf#page=149&rect=33,488,403,523|南怀瑾 老子他说, p.135]]

> 五色令人目盲，五音令人耳聋，五味令人口爽，驰骋畋（tián）猎令人心发狂，难得之货令人行妨。是以圣人为腹不为目，故去彼取此。

# 十三
![[南怀瑾 老子他说.pdf#page=152&rect=40,486,394,524|南怀瑾 老子他说, p.138]]

> 宠辱若惊，贵大患若身。何谓宠辱若惊？宠为下，得之若惊，失之若惊，是谓宠辱若惊。何谓贵大患若身？吾所以有大患者，为吾有身，及吾无身，吾有何患！故贵以身为天下，若可寄天下；爱以身为天下，若可托天下。

# 十四
![[南怀瑾 老子他说.pdf#page=157&rect=35,488,398,523|南怀瑾 老子他说, p.143]]

> 视之不见名曰夷，听之不闻名曰希，搏之不得名曰微。此三者不可致诘（jié），故混（hùn）而为一。其上不皦（jiǎo皎），其下不昧。绳绳(mǐn mǐn )不可名，复归于无物，是谓无状之状，无物之象。是谓惚恍。迎之不见其首，随之不见其后。执古之道，以御今之有，能知古始，是谓道纪。
